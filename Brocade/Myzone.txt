Cisco Zoning

Step1:Adding ports under vsan

switch# config t----------------------> First Enter config t mode.
switch(config)# vsan database--------->From config mode,Next enter into vsan database folder.
switch(config-vsan-db)#
switch(config-vsan-db)# vsan 1618----->Now Enter inside vsan which we need to add ports.
vsan 1618 interface fc1/46------------>Now add port into vsan
exit---------------------------------->Exit after adding port


Now you're in config mode.


Step2:Creating alias name for server wwpn's

# config t
(config)# device-alias database-------------------------------------------------------->From config mode get into device-alias database folder.
(config-device-alias-db)# device-alias name ukcccl915_01 pwwn 10:00:70:10:6f:e8:4f:26-->Now you're in "device-alias database", now create alias for server port
(config-device-alias-db)# exit---------->exit from device-alias database mode.
(config)#device-alias distribute ####--------------------------------------------------->From config mode make announce as alias created with this command
(config)# device-alias commit----------------------------------------------------------->Now commit the device-alias.
(config)# exit--------------------------------------------------------------------------->Now exit from config mode also.


Step3: Create zone name and add members to it.

ALL the below steps to be executed in config mode.

config t
zone name z_ukcccl915_01_VMAX1102_2D5 vsan 1618---------->creating zone name under desired vsan.
member device-alias ukcccl915_01------------------------->Now we are under the zone adding server alias to zone(which we created in previous step).
member device-alias VMAX1102_2D5------------------------->Adding storage alias to zone.
exit
